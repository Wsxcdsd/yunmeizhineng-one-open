# 云莓一键开门 · 桌面小部件修改包（共存版）

## 这是什么

给 [zxy19/yunmei_unintelligent](https://github.com/zxy19/yunmei_unintelligent)（云莓不智能）
加一个**真正的桌面小部件**：桌面上放一个 1×1 的"开门"按钮，

> **点一下 → 屏幕停留在桌面不动 → 门开了 → 弹一条 Toast（开门完成 / 电量 / 失败原因）**

原版的"桌面快捷方式"和"下拉磁贴"点击后都会拉起 App 界面；本修改用一个**完全透明的
中转页**承载开门逻辑：用户全程停留在桌面，什么都不闪。

**本包是"共存版"**：App 包名改成 `cc.xypp.yunmeiui.mod`、名字改成「云莓一键开门」，
与手机上已装的官方 App **互不干扰、同时安装**，官方版的登录和数据完全不受影响。
新装的这个需要单独登录一次账号。

> 透明页在 manifest 里的四个属性缺一不可：`taskAffinity=""`（独立任务栈，不会把 App
> 界面顶出来）、`excludeFromRecents`、`noHistory`、透明主题。
> 为什么用透明 Activity 而不是纯广播：第一次使用要弹蓝牙权限框（只有 Activity 能弹），
> 且 Activity 存活期间进程不会被回收，蓝牙操作最稳。

## 第一步：GitHub 自动打包（电脑不用装任何东西，全程浏览器）

1. 注册/登录 [github.com](https://github.com)；
2. 打开 `github.com/zxy19/yunmei_unintelligent`，点右上角 **Fork → Create fork**
   （把仓库复制一份到自己账号下）；
3. 进入**你自己的 fork**（地址是 `github.com/你的用户名/yunmei_unintelligent`）；
4. 点 **Add file → Upload files**；
5. 把本目录下的 **`app` 整个文件夹** 和 **`.github` 整个文件夹** 拖进上传区域
   （浏览器会保留文件夹结构，同名文件自动覆盖；`.github` 开头的文件夹在
   Windows 资源管理器里可见，直接拖即可）；
   - 确认页面显示的文件列表里有 `app/build.gradle`、`app/src/main/...`、
     `.github/workflows/build-apk.yml` 这些路径；
6. 拉到页面底部点 **Commit changes**；
7. **关键一步**：点仓库的 **Actions** 标签页 —— fork 来的仓库 Actions 默认是关闭的，
   页面会提示需要确认启用，点 **I understand my workflows, go ahead and enable them**；
8. 左侧选 **Build APK** → 右侧 **Run workflow → Run workflow**（或刚才 push 时已自动跑）；
9. 等约 3~5 分钟变绿色 ✓，点进该次运行，页面底部 **Artifacts** 下载
   `yunmei-widget-debug-apk`，解压得到 `app-debug.apk`；
10. 把 APK 传到手机（微信文件传输助手 / QQ / 数据线都行）。

**构建失败排查**：
- 日志里有 `Could not resolve ... FastBleLib`：jcenter 停运导致。在你 fork 里编辑
  `settings.gradle`，把 `jcenter()` 改成 `maven { url 'https://jitpack.io' }`，重新提交；
- 日志里有 `Unsupported class file major version 61`：JDK 版本不是 11，检查
  `build-apk.yml` 里 `java-version: '11'` 是否还在。

## 第二步：手机安装

1. 打开下载的 APK → 系统提示"禁止安装未知来源"→ 点设置进去，允许
   **来源应用**（比如你的文件管理器/微信）安装 → 返回继续装；
2. 装好后桌面出现「**云莓一键开门**」图标，原官方 App 原样保留。

## 第三步：首次设置（一次性，约 2 分钟）

1. 打开「云莓一键开门」→ 登录你的学号密码 → 确认门锁已添加（和官方 App 一样的操作）；
2. **把要开的锁设为默认**：点进锁详情 → 设为默认（小部件开的就是这把默认锁）；
3. 按提示授予两个权限：**位置**（扫蓝牙要用）和 **附近设备/蓝牙**——
   路径：设置 → 应用 → 云莓一键开门 → 权限，把"位置"和"附近设备"都设为允许；
4. App 设置里确认"快速连接"是打开的（默认开）。

## 第四步：添加桌面小部件

长按桌面空白处 → 底部 **插件/小部件** → 找到「云莓一键开门」→ 把 **一键开门** 拖到桌面。
可以长按小部件拖动角标缩放大小。

## 第五步：国产系统后台设置（realme UI / ColorOS / MIUI 等，重要，防止被系统限制）

| 设置 | 路径 |
|---|---|
| 自启动允许 | 设置 → 应用 → 应用管理 → 云莓一键开门 → 自启动，允许 |
| 关闭应用速冻 | 设置 → 电池 → 更多设置 → 应用速冻，找到本 App 关掉 |
| 无限制耗电 | 同上页面 → 耗电管理 → 允许后台运行/不限制 |

> 点小部件那一刻是前台操作，不受速冻影响；以上设置主要保证蓝牙流程稳定不被打断。

## 日常使用

**点桌面按钮 = 开门。** 屏幕不跳任何界面，只有 Toast：
- 成功：`开门完成` + `电量:xx%`
- 失败：具体原因（设备未找到 / 连接失败 / 蓝牙没有启用……）
- 连点保护：正在开门时再点，只提示"正在开门，请稍候"

小部件上显示的锁名是放置时的快照；**实际开哪把锁以点击瞬间 App 里的默认锁为准**
（想开别的锁：App 里换默认锁后，长按小部件删掉重加一次即可刷新名字）。

## 排障

| 现象 | 处理 |
|---|---|
| 点小部件没反应也没 Toast | 打开 App 确认默认锁在、App 内能正常开门；检查上面第五步的后台设置 |
| 第一次点弹了权限框 | 正常，授完权后**再点一次**小部件即可 |
| 开门变慢（~10 秒） | 锁轮换了蓝牙地址，会扫描一次自动记住；本包已修默认锁不同步的 bug，正常只慢第一次 |
| 安装报"与已装应用冲突" | 不应该出现——本包包名已改为 `.mod`；若你拿到的不是本包构建的 APK，检查 build.gradle |
| 想让下拉磁贴也"无界面" | 把 `serviceOpenDoor.java` 里的 `new Intent(this, MainActivity.class)` 改成 `new Intent(this, UnlockActivity.class)`（可选） |
| 想恢复成"替换版"（不要共存） | `app/build.gradle` 里 `applicationId` 改回 `cc.xypp.yunmeiui`，`shortcuts.xml` 的两处 `targetPackage` 也改回去，`app_name` 改回「云梅不智能」 |

## 安全提醒

这把锁的开门密钥（`lockSecret`）是**静态永久密钥**（开锁报文无防重放设计），存在 App
的加密存储里。别把 APK 发给陌生人。自用没问题。
